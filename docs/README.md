## 当前换机恢复规则

**源机只读、目标机按确认清单覆盖，不要求双端备份或目标旧配置备份。**
源机不上传助手、不安装、不改配置、不通知或重载。兼容的纯设置文件可整文件
覆盖；账号、授权、容器、运行状态和高敏隔离策略不随之照搬。覆盖后仍核对
格式、权限和真实消费者。没有目标旧状态副本就不承诺回滚；完整灾备只在另行
授权的抹机、移除环境或数据操作中按需安排。历史备份记录不作为新轮次门槛。
