# AutoSkipGuard 0.4.6

正式文件：AutoSkipGuard_0.4.6_arm64.dylib
适用：iOS 15+ / arm64，TrollFools（巨魔注入器）应用内注入。

1. 在巨魔注入器中停用或移除目标App的旧AutoSkipGuard，勿同时加载新旧两版。
2. 选择本目录dylib注入并启用，正常重开App；App更新后可能需要重新启用。
3. 只有确认关闭，顶部才显示“AutoSkipGuard · 已关闭广告”。没有提示不能直接算本插件成功。
4. 误点、卡顿或闪退时停用这个插件，不必清App数据或改系统/RootHide。

每轮从App激活起8秒，原生控件优先；OCR失败完成后0.25→0.5→1秒退避，后续间隔封顶1秒。正式版关闭诊断日志，定位缓存关闭。

这是个人设备发布版本，不是全App兼容保证。同功能调试构建12受控真机场景通过；正式无诊断构建本地校验通过，尚未单独真机复验。8秒后的广告、部分自绘/动图仍可能漏；没有CPU/内存/电量增量承诺。

可维护源码与完整冻结快照保存在项目plugins/auto-skip-guard/及releases/0.4.6/。iCloud仅保留正式包、说明和校验信息。
