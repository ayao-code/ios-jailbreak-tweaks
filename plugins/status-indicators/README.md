# StatusIndicators（状态指示）

轻量状态栏插件，仅注入 SpringBoard，不依赖 NiceBarX，不修改系统专注模式或其他插件配置。

## 当前正式版本 0.1.2

- 已生成并安装 RootHide 0.1.2 到 12 mini 和 14 Pro Max，远端交付采用只含本插件的发布分支，不创建 GitHub Release 页面；详见 [发布记录](RELEASE_0.1.2.md)。正式0.1.1与必要回滚基线保留，中间候选包已移出仓库。
- 横屏VPN/网速/静音/专注位置分组完整；原生状态栏横屏隐藏时可用SpringBoard旋转容器回退显示，无业务App注入。
- 支持独立横屏颜色，默认继承原色；用户目标横屏固定白色，竖屏原色及动态居中不改。导出53键，旧schema=1部分导入兼容。
- 加固单次几何稳定确认/隐藏停采样，正式包关闭诊断。同进程四轮各30秒资源对照：CPU活动差约0.0113个百分点、footprint均值差约0.0123MiB；不是全部常驻内存/长期耗电保证。
- 配置及实际函数局部回归通过，短信横屏与用户确认的其他App、桌面/锁屏/控制中心已有相关实机证据；按用户要求不再逐项验收，多任务和全App/双方向等未扩大为实测通过。
- 原无Focus回滚基线及历史正式包保留，不删除原设置；[0.1.1历史发布](RELEASE_0.1.1.md)。

## 显示功能

- VPN、物理接口上下行网速、可选总静音与专注模式图标。
- 总静音只读取 `ayao.lockaudioprofiles` 的 `totalSilenceEnabled` 并监听其通知，不修改开关、音量或配置。专注只读系统活动状态，勿扰/月亮、个人/小人、工作/公文包、游戏/手柄；未知模式为其他。名称“游戏”做精确兼容，不模糊匹配或读取旧 UI 快照。
- 颜色、字重、透明度、图标/文字、大小均可配置。VPN 默认共用网速字号；可单独开启独立大小。系统符号字形和数字视觉高度不保证相同。
- 横向为宽度百分比，纵向为相对中心点偏移（-25～100 点）。固定锚点不随灵动岛布局移动；过渡可能短暂隐藏。动态居中按活动的 VPN/静音/专注/网速重新排列，网速预留固定宽度，间距可调。
- 网速默认 KB/s 纯数字，支持单/双行、箭头、单位、顺序、小数位及字符间距；真实零流量可隐藏。初始/长间隔/计数重置/接口集合变化是未知差分，不当作实测零；可选择仅把未知显示为 0，下一轮有效差分恢复。
- 控制中心、锁屏、复用池宿主和不满足可见性的状态不显示；横屏隐藏原生状态栏时，经过独立锁屏/系统遮挡检查可使用旋转容器显示。不改原生状态栏、Waqt 或高敏 App 的 RootHide 隔离，不向业务 App 注入。

## 配置导入/导出

主设置页提供导出和导入，共用纯校验 `SIConfigCodec` 与原有 `SISettingsStore`：

- 新导出包含 **53 个白名单显示设置**，补齐静音位置/大小、默认值和未显式保存的横屏继承值。默认值来自打包的设置资源，不额外手写另一套；导出是独立 XML 文件，不改当前配置。
- 文件 schema 保持 `version=1`。导入支持 XML/binary，旧版部分配置仍只覆盖文件包含的键，未包含设置及非目标历史键不变。导出展开的横屏值表示当次有效布局，之后修改竖屏不会自动改动这些显式横屏值。
- 读取文件上限 64 KiB，解析前有界读取；检查根结构、身份、版本、键白名单、值类型、有限数字、范围/整数性、颜色和文字长度。异常/空/超大文件安全拒绝，不发送错误类型的数值转换消息。
- 旧 VPN 半盾值 2 转为新盾值 1，文字值 3 保持；旧磁盘数字字符串导出时校验并转换为数字。坏值不静默丢弃。系统专注规则、允许联系人、账号、RootHide 隔离及总静音开关不在导出内容中。
- 用户确认后才一次合并保存；保留原配置 XML/binary、属主和权限，原子替换、语义回读成功后再通知。取消/校验失败不改当前配置。保留单个 last-good 备份及锁文件，不滚动增长。
- 文件名使用时间和短随机编号；分享完成后清理临时文件。设置预览尊重显示开关及指定图标，只用示例状态，不发起系统状态查询或网速采样。

## 资源边界

- 当前一个活动显示集，包含 3 个 UIImageView 和 3 个 UILabel；竖屏一个非交互透明覆盖窗口，横屏使用现有旋转宿主容器，仅可见时展示，禁用/窗口迁移时清理。宿主集合为弱引用，没有“最多 8 个”的现行硬上限；窗口树发现每次最多 512 个视图。
- 网速一个 serial utility 队列和一个计时器，默认 2 秒、范围 1～5 秒；隐藏/熄屏/禁用网速后取消。每次接口读取临时缓冲 64 KiB、最多 32 个物理接口并立即释放，不联网、不累计采样历史、不重复计算 VPN 隧道流量。
- Focus 为独立 utility 状态订阅，启用一次查询初值，随后事件更新；关闭显示/主开关或销毁时注销，代次拒绝迟到回调。无持续轮询、新增日志或主线程同步状态 IPC。
- release 构建 `SI_DIAGNOSTICS=0`，临时诊断树/JSON 写入不编入。配置只在用户操作时读写，不新增常驻扫描。
- 四轮同进程短时开关CPU/footprint结果见发布记录；开关差值不含全部常驻代码内存，未证明长时耗电或长期无泄漏。

## 构建与验证

目标 iOS 16，SDK 16.5，源码与包在同一目录；所有 `.deb` 在 `packages/`。

```sh
# RootHide；本轮只构建这个目标
make THEOS="$ROOTHIDE_THEOS" THEOS_PACKAGE_SCHEME=roothide ARCHS=arm64e \
  PACKAGE_VERSION=0.1.2 clean package FINALPACKAGE=1
# 普通 rootless 历史构建方式，本轮未重建/验证，不能安装到 RootHide
make THEOS="$THEOS" THEOS_PACKAGE_SCHEME=rootless clean package FINALPACKAGE=1

# Mac 本地算法、配置、状态回归
sh tests/run-config-tests.sh OUTPUT_DIRECTORY
sh tests/run-focus-monitor.sh OUTPUT_DIRECTORY
```

本轮 RootHide Theos 为 `958fea4f779943505b15b93c88bb4db8d97b346d`；包 `iphoneos-arm64e`、安装名使用官方 `.jbroot`。普通 rootless `iphoneos-arm64` 不与它互换。

配置测试覆盖全部键、完整/部分往返、类型/范围拒绝、文件大小边界、原格式/非目标键/备份/通知；预览 24 种开关/样式组合；Focus/VPN 生命周期及格式/速率回归通过。测试使用真实 codec/monitor/存储实现，假宿主/视图只验证边界，不冒充 UI 验收。

用户已反馈安装后的 `config1` 整体正常，该反馈不是逐场景的独立截图验收；iPad 分享弹层、全 App/横屏/所有动画及插件专项耗电不扩大为已验证。历史与当前验证见 [验证记录](tests/VALIDATION.md)，Focus 设计见 [研究记录](docs/FOCUS_MINIMAL_FIX.md)。
