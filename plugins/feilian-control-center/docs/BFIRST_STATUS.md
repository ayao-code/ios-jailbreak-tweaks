# B 优先切换与准确状态：bfirst3

2026-11-15；iPhone13,1 / iOS 16.3.1 / RootHide。
用户明确授权 B 优先，由系统处理旧隧道互斥切换；主要范围 Easy、飞连、
Hotspot，Jump 和 GOFast 仅 Beta。

## 实现

- 长按选择 B：核对具体源/目标配置，后台唤醒并认证 B，立即发送原生连接。
- 不调用 A 的原生停止，不启动 A、不做后台清理 A、无8秒等待停止结果。
- 只有用户主动点关闭开关才调用当前目标的原生断开；列表外连接仍受保护。
- 已认证的 B socket 直接发送命令，不重复 probe/握手消费15秒有限预算。
- 系统确认准确 B 是唯一已连接目标，并稳定0.75秒才保存新选择；失败时
  如实显示当前实际状态，不把“请求发出”或“连接中”算成功。
- IPC 超时后关闭本次请求并有限观察系统4秒。若准确 B 稳定连接，记为
  系统状态确认成功；明确权限/原生失败不走这个分支，不伪造辅助回执。
- 控制器 timeout revision 防止旧阶段已取消定时器误结束新阶段。
- 飞连去掉重复 UIKit 后台任务，短时回读其原生 manager 状态补齐迟到回执，
  不直接构造登录/凭据/隧道配置，也不跳过原生 connect 流程。
- 安全版的空检查、单次主队列断言释放和15秒主动到期继续保留，没有无限保活。
- 固定许可发布器在同一 data volume 原子移动已root属主的64字节许可，
  不在 App tmp 创建/拷贝/chown 中间文件；目标leaf使用 mv -T，拒绝目录陷阱。
- 新增最多128KiB并保留一份轮转的真实用户操作日志 ayao.vpn-operations.log
 ，只记提供方、阶段、结果与耗时，不记配置ID、
  App容器、audit token、端点或凭据；不得改高敏App设置。

## 真机证据

真实 SpringBoard 调用已安装模块的同一 select/buttonTapped 实现，不复制
业务 controller 或 IPC。不是实际触摸/长按视觉验证；USB暂未连接，使用
之前固定密钥验证的无线原设备，没有猜测新目标或改变RootHide隔离。

操作日志直接观察到：B connect-dispatch 后，A 进入disconnecting，再进入
disconnected，B connecting/connected。代码没有发送A停止，证明本设备上
测试的同类配置确实由系统仲裁，不能推广到所有企业/按App VPN。
