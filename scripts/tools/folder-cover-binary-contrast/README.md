# Original PrimalFolder geometry contrast

Executes the actual audited ARM64e `sizeForLayout` and `rectAtIndex` machine
instructions in Unicorn. Does not load third-party code into any phone or
change the original Mach-O. Code hash must match the inspected 0.1.2 slice.
PAC return signing is skipped only inside emulation; ObjC/UIKit dependencies
and original grid geometry are explicit, fixed stubs. No paid authorization
code, network or device operations. Use your own legitimately obtained binary.

The A/B/A contrast toggles only `disableAL`, with an initial shared library
flag of one. It also includes a fresh-flag control. An emulator result proves
this branch scenario is executable, not that the device saw exactly those
inputs, nor that Bolders alone has a bug. It is not live GUI validation.

Run in a local virtualenv with Unicorn/Capstone, passing the verified thin
binary and an output JSON path. No original addon binary is bundled here.
